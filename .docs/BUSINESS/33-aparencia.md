# 33 — Aparência (modo noturno)

## Regra
- Opções: **Automático (padrão)** · Claro · Noturno — Perfil → Configurações → Aparência (segmentado).
- **Automático segue o tema do celular** e muda na hora quando o celular muda.
- A escolha fica salva no aparelho. Descrição sob o título: “Segue o tema do celular” / “Modo claro” / “Modo noturno”.
- Troca com transição de fundo de 400 ms.
