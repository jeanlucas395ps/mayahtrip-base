# 14 — Métodos de pagamento

## Objetivo
Ligar ou desligar cada método que a Asaas oferece no site de planos (`WEB/04`). O app não tem checkout.

## Métodos
- Cartão de crédito
- Boleto
- Pix

## Regras
- Método desligado não aparece para o usuário assinar.
- Desligar não cancela assinatura já paga com aquele método.
- Pelo menos um método fica ligado. O último não desliga.
